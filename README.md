# Short Video Clipper

Chrome 扩展，把网页上的视频保存为文件。支持 X、LinkedIn、Instagram、TikTok 和普通网页。

## 安装

1. 打开 `chrome://extensions`，开启右上角的「开发者模式」。
2. 点「加载已解压的扩展程序」，选择本文件夹（从 GitHub 下载的 ZIP 需先解压）。
3. 在工具栏的扩展菜单里固定 Short Video Clipper，再刷新已经打开的视频页面。

## 使用

1. 让视频出现在屏幕中，播放几秒。
2. 点工具栏图标，选择视频和质量，点「保存」。

只有页面提供完整视频文件时才能保存。只用分段流（HLS、DASH）、直播或加密播放的视频无法保存。

扩展在上述四个平台常驻读取视频地址，在其他网站只在点击图标时读取一次，不上传任何数据。请只保存你有权下载和使用的视频。
